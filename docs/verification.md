# 验证记录

## 0.9.0 关键词高亮与工具栏

便签高亮改为每张便签独立的关键词规则。选中的文字在当前便签中全部匹配，固定红底白字；新增、粘贴、修改与撤销后更新匹配。采用绘制范围而非改写编辑节点，保留正文、选区、滚动位置和原生输入撤销。中文输入法组合期间延后匹配刷新。关键词随 notes.json 和窗口本地恢复副本保存，旧版选区底色在打开时转换为关键词。串行保存成功后不再用旧快照覆盖当前状态，避免快速修改规则时丢失新规则。

工具栏文字按钮不再沿用图标按钮的固定 27 px 宽度，改为按文字宽度排版、禁止短标签换行，并为应用工具独立分组留出间距；窄窗口按组换行。

已执行并通过 TypeScript 严格类型检查、Vite 生产构建及 Windows Rust release 编译，构建命令为 `npm run desktop:build -- --no-bundle`。发布程序 `release/moye.exe` 产品版本为 0.9.0，大小 5,514,240 字节（5.51 MB），与构建文件 SHA256 一致：`6989EF6F1464F4F822B6B98D88DC503BCA7A9878A3FABD7EC33E6474E5A936C4`。手写应用源码最长为 `src/main.ts`，455 行。

按用户要求，不运行自动化、浏览器或桌面交互测试，不生成安装包。关键词高亮、输入法与工具栏实际运行表现尚未实测。下方旧版记录仅作历史保留。
