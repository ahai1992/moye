# 墨页 0.9.0

Windows 64 位本地 Markdown 编辑器。

## 运行

双击本目录中的 `moye.exe` 即可使用。打开的是独立桌面窗口，无需运行命令，也不需要安装 Rust、Node.js 或编译工具。

本版仅提供 EXE。点击主窗口「关联 MD」→「注册并打开默认应用设置」，在 Windows 默认应用设置中选择「墨页」，关联 `.md`、`.markdown`、`.mdown` 或 `.mkd`。注册的是当前程序的位置，关联后请勿移动 EXE。

程序使用系统 WebView2，大多数 Windows 10 / 11 电脑已具备。

## 编辑

- 文件、编辑、格式和显示按钮都在顶部工具栏，悬停可查看按钮说明和快捷键。「便签」「配色」「关联 MD」各自保留文字宽度和间距，窗口变窄时按组换行。
- 点击文件夹图标「打开」选择本地 Markdown 文件，每个文档使用独立标签；再次打开同一文件会切换到已有标签。
- 「预览」中可直接修改文字；工具栏「源码」切换到 Markdown 原文，始终只有一个编辑区。
- 使用 `Ctrl+S` 保存，`Ctrl+Shift+S` 另存为，`Ctrl+O` 打开。
- 双击公式、图表、脚注或文档属性，可修改对应 Markdown 内容。
- 切换标签保留各自的内容、撤销历史和滚动位置；`Ctrl+N` / `Ctrl+T` 新建，`Ctrl+W` 关闭，`Ctrl+Tab` / `Ctrl+Shift+Tab` 切换标签。

## 桌面便签

- 主窗口工具栏点击「便签」→「新建便签」，可以创建多个独立便签窗口。便签上的「＋」也可继续新建。
- 默认浅黄色纸面；「纸」调整便签背景色，「字」调整文字颜色。点击「钉」开启或取消置顶，置顶后显示在其他普通窗口上方。
- 选中文字（如「你好」）后点击「亮」，当前便签所有相同文字都显示为红色背景、白色文字。后续新增、粘贴或修改出来的相同文字也会自动高亮；每张便签的关键词独立保存，重启后继续生效。
- 要取消某个关键词，选中完整的同一关键词再点「亮」。仅取消这条规则，其他关键词继续生效。旧版黄色选区高亮会自动转换为关键词规则，原有内容保留。高亮更新不重建正文，也不改变编辑位置。
- 便签顶部「删」或主窗口便签列表的「删除」均可删除便签。确认后移除便签并关闭其窗口，无法撤销；「×」仍只收起并保留内容。
- 按住顶部中间的拖动把手移动便签；拖动四条边或四个角自由调整大小，最小为 220 × 160。
- 内容自动保存，底部显示保存状态；保存失败会提示并自动重试，也可点击「重试保存」或按 Ctrl+S。
- 「×」仅收起便签，内容保留。在主窗口「便签」列表中可再次打开。退出墨页时先等待便签保存，再关闭所有便签；下次打开墨页恢复上次显示的便签及其位置、大小、颜色和置顶状态。
- 便签与文档分别保存，不会自动覆盖你的 Markdown 文件。本地保存文件为应用数据目录中的 notes.json，notes.backup.json 保留上一版；请勿清理应用数据。异常断电只能恢复最后成功保存的内容。

本版按要求未运行自动化或桌面交互测试，仅执行构建。

## 主窗口整体配色

点击工具栏「配色」，分别设置「背景色」和「文字颜色」。配色统一作用于正文、源码、工具栏、标签栏、目录、状态栏和应用内弹窗，即时生效，下次启动保留；点击「恢复默认」还原原有配色。此设置只改变显示，不修改文档。

## 快捷复制

在预览模式中，将鼠标移到代码块、段落、标题、列表、引用或表格上，点击右上角「复制」。成功后按钮显示「已复制」。

代码复制时保留缩进和换行，不包含 Markdown 的代码围栏；普通文本不带 HTML 标签，表格以制表符分隔单元格。复制不会修改文档或改变滚动位置。

标题上的「复制」会复制整个章节的 Markdown，包括标题本身、子标题、列表和代码块，范围到下一个同级或更高级标题之前。

## 修改或替换当前块

在预览模式中，将鼠标移到目标段落或代码块上，点击「复制」左侧的「替换」，会打开大输入框。

- 输入框只包含当前块：代码块显示代码正文，其他文本块显示该块的 Markdown，便于保留加粗、链接、列表、表格等格式。
- 修改后点击「应用修改」或按 **Ctrl+Enter**。只更新当前块，并保留滚动位置；代码块会保留原代码语言。
- 点击「取消」或按 **Esc** 放弃本次修改；未修改直接确认不改写原文。
- 应用后可按 **Ctrl+Z** 撤销。清空普通段落后应用可删除该段落。
- 已有本地文件仍需按 **Ctrl+S** 手动保存；未命名文档继续按既有规则自动暂存。

## 父子层级与操作范围

- **标题**：支持 `#`、`##`、`###` 至 `######` 六级，父标题包含所有下级内容。下划线式标题（文字下方的 `===` 或 `---`）分别作为一级、二级标题。
- **章节示例**：在 `### 镜022` 上复制或替换，会包含该标题下的列表、代码块及四至六级子标题；遇到下一个 `###`、`##` 或 `#` 标题结束。
- **列表项**：每一个 `-`、`+`、`*`、`1.` 或任务列表项都是独立操作对象。父列表项包含缩进的子列表，子项也可单独复制或修改。
- **引用**：外层 `>` 包含内层 `>>`，内层引用可以独立操作。引用或列表项内的标题不会把章节范围延伸到容器之外。
- **代码块**：包括标注为 `text` 的文本代码块，整体独立。内部的标题符号、列表符号和空行均按代码正文处理。普通段落和表格也可分别操作。
- **分隔线**：单独的水平分隔线只属于所在章节，不建立新的标题层级。

章节替换的大输入框会从内容开头显示。点击「应用修改」只更新选中范围，保留阅读位置；支持一次撤销和重做，并能与普通输入按顺序撤销。

## 搜索与替换

- **Ctrl+F** 打开搜索弹窗，**Ctrl+H** 打开替换弹窗；顶部工具栏也有搜索图标和「替」按钮。
- 搜索在当前标签的 Markdown 原文中进行。从预览调用时会切换到源码，直接显示匹配位置和高亮。
- 输入查找内容后显示匹配数量；可选择「区分大小写」和「全词匹配」。默认按普通文字查找，例如 `a.b` 中的句点不会被当作通配符。
- 点击「上一处」「下一处」前后查找；也可用 **Enter / Shift+Enter**。到达文末或开头后循环查找。
- 「替换当前」修改选中的匹配项；「全部替换」修改本标签中的全部匹配项，替换为空可删除匹配内容。
- **Esc** 关闭弹窗；关闭后按 **Ctrl+Z** 可撤销替换。「全部替换」可一次撤销，已有本地文件仍需手动保存。

## 目录与字号

- 左侧自动列出 `#`、`##`、`###` 至 `######` 六级标题，按层级缩进；点击即可跳转，源码和预览模式都支持。
- 编辑标题后目录会自动更新，切换标签时显示对应文档的目录；同名标题可以分别跳转，代码块中的 `#` 不会误当作标题。
- 点击左上角「目录」可收起或展开侧栏，程序会记住选择。
- **Ctrl＋滚轮向上**放大字号，**Ctrl＋滚轮向下**缩小字号，工具栏大小保持不变。
- 字号在源码和预览中同时生效，并在下次启动保留；**Ctrl+0** 或点击底部字号可恢复默认。显示缩放不会改写文件内容。

## 自动暂存与临时保存

- **尚未保存为实际文件的未命名文档**会自动暂存到本机，下次启动自动恢复。底部状态栏会显示「已自动暂存」。
- **已有本地文件不自动保存修改，也不自动暂存正文**。请用 `Ctrl+S` 手动保存；有未保存修改时关闭标签或退出，会提示保存、放弃或取消。
- 点击工具栏「临时保存」或按 `Ctrl+Alt+S`，可立即暂存当前未命名文档。对已有文件使用时，会创建并暂存独立的「临时副本」标签，原文件不会被覆盖。
- 关闭整个窗口会保留未命名草稿，下次打开恢复；明确关闭某个未命名标签并选择放弃，会移除该草稿的恢复记录。
- 将草稿正式保存为文件后，该标签停止自动暂存正文。下次启动已有文件标签时，读取磁盘上的最新内容。
- 正常退出会等待暂存完成；断电或程序异常退出，只能恢复最后一次成功暂存的版本。如提示暂存失败，请手动保存为文件。

## 与其他软件同时编辑

墨页读取完成后立即释放文件句柄，不持续锁住文档，其他软件可以读取和修改。

点击或切换到该文件标签、重新回到墨页窗口时，会检查磁盘内容。检测到修改后，可选择「重新加载」读取最新版本，或「保留当前内容」继续编辑。重新加载会放弃当前标签的未保存修改；文件已移动或删除时，当前内容仍然保留，可以另存为。

选择保留后，手动保存仍会检查冲突，避免覆盖外部修改。需要保留两份内容时使用「另存为」。

## 显示换行

工具栏右侧有三个快捷按钮，源码和预览都支持：

- **不换行**：长行不自动折行，可横向滚动查看。
- **按窗口换行**：随当前窗口宽度自动换行，充分利用编辑区；这是默认方式。
- **按页面换行**：按固定 A4 宽度（210 mm）排版，窄窗口中可横向滚动。

这些设置只改变显示效果，不向文件插入换行符。程序会记住选择；源码与预览之间切换会保留各自的滚动位置。

支持常见 Markdown、表格、任务列表、代码高亮、数学公式、Mermaid 图表与本地图片。当前支持 UTF-8 文档，文档上限 16 MiB；相对图片放在文档目录或其子目录，其他位置图片可用工具栏嵌入。外部图片不自动联网加载。

本版仅提供主程序，约 5.51 MB；系统 WebView2 运行环境占用不计入此大小。
